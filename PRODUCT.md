# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Разработчик (русскоязычный интерфейс), который ежедневно работает в Windows и запускает несколько AI-кодинговых CLI одновременно: Claude Code, Codex, OpenCode, Gemini CLI, Grok CLI, Copilot, Devin и др. Его задача — чтобы все агенты ходили через одну точку, видеть куда уходят запросы и сколько это стоит, и входить в аккаунты провайдеров без ручной возни.

## Product Purpose

Локальный прокси-шлюз и панель управления: принимает API-запросы от AI CLI по нескольким протоколам (anthropic, openai, sandbox-*), маршрутизирует их на выбранную модель/аккаунт, логирует каждый запрос (модель, усилие, токены, задержка, статус) и считает траты — реальные списания и расчётный эквивалент API отдельно. Управляет установкой и входом в аккаунты CLI.

## Positioning

Один локальный шлюз для всех агентских CLI сразу — с журналом, квотами и тратами в одном месте; соседние продукты либо только проксируют, либо только показывают статистику.

## Operating Context

- Десктопное приложение Tauri 2 (Rust + React 19 + Tailwind 4) под Windows; фронт рендерится в webview.
- Работает постоянно в фоне рядом с терминалом и IDE; пользователь смотрит в него периодами — проверить лог, квоту, траты.
- Экраны: Обзор, Аккаунты, Чат, Модели, Траты, Логи, Настройки.
- Вход в аккаунты CLI — через реальное окно терминала с интерактивным логином.

## Capabilities and Constraints

- Светлая и тёмная темы — обе равноправны.
- Акцентные цвета на выбор: Оранжевый (основной), Зелёный, Синий, Серый — названия только по-русски.
- Локальные данные: SQLite, конфиг, API-токен `aipx_…` генерируется при первом запуске.
- Не выдумывать точные траты: расчётные суммы помечаются `~`.

## Brand Commitments

- Имя продукта: AI Proxy.
- Оранжевый — фирменный акцент, сдержанное использование.
- Без заголовков капсом, без консольного/терминального начертания как основного шрифта UI.
- Иконки провайдеров — настоящие логотипы, не буквенные заглушки.

## Product Principles

- Честные числа: фактическая модель и реальные списания отдельно от оценок.
- Инструмент, а не витрина: плотность и читаемость важнее эффектов.
- Один взгляд — один ответ: статус, траты и проблемы читаются без скролла.
